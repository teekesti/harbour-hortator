# Cap Set/Exercise nesting at exactly two levels, with every Exercise belonging to a Set

Workouts need a Round-repeat at the Exercise level and a separate Round-repeat at a grouping level (a Set). The obvious generalization would let a Set contain other Sets recursively, and let Exercises optionally sit outside any Set. We rejected both: nesting is capped at exactly two levels (a workout is a list of Sets; a Set is a list of Exercises; an Exercise cannot contain anything), and every Exercise always belongs to some Set — there are no top-level loose Exercises. A workout that looks like today's flat list is just the degenerate case of N Sets, each with one Exercise and `rounds = 1`.

Picked over arbitrary recursion because no real workout pattern (EMOM, supersets, circuits) needs a third level, and the cap removes a whole class of UI/state-machine complexity (infinite-depth rendering, recursive flattening) for no expressive loss. Picked "every Exercise lives in a Set" over an optional top-level union (bare Exercise *or* Set) because it collapses the top-level list to a single, uniform type — no branching on "is this item a Set or an Exercise" anywhere in the model or UI.
